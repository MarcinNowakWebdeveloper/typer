# Typer

Typer to aplikacja webowa służąca do organizowania i prowadzenia rozgrywek typu **typer sportowy**.
Projekt został stworzony jako pełnoprawna aplikacja SPA z backendem opartym o Symfony oraz frontendem napisanym od podstaw w Vue 3.




---

## Stack technologiczny

### Backend

* PHP 8.4
* Symfony 8
* API Platform
* Doctrine ORM
* MariaDB / MySQL
* JWT Authentication

### Frontend

* Vue 3 (Composition API)
* Vite
* Vue Router
* Pinia
* Axios
* Vue I18n
* Bootstrap 5
* Bootstrap Icons
* ECharts

---

## Wymagania

* PHP 8.4+
* Composer
* Node.js 22+
* npm
* MariaDB 11+ (lub kompatybilny MySQL)
* DDEV (opcjonalnie)
